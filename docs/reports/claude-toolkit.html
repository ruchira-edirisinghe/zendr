Claude tools worth bringing into Zendr

I read every mod in the herdr gallery and kept the ones that make working with Claude Code faster or safer. Each pick below says what it does, why it fits Zendr, how it would arrive, and who made it. Every one gets its own on/off switch in Settings.

Found while reading the gallery

Herdr already has a free Android and iPhone app

The official Herdr mobile app (Google Play, free, open source) talks to herdr-core over SSH, and Tailscale gets it there from anywhere. Zendr runs on herdr-core, so the phone app can see Zendr's terminals: an inbox of who needs you, the live terminal with Esc, Ctrl and arrow keys, a compose box with dictation, and your spaces.

That changes the remote-control plan. The quickest route is Tailscale plus the Windows SSH server plus this app, with no APK to build. The Zendr web app and the code-pairing for other PCs still add things it lacks: a Zendr-branded install, a pairing code instead of SSH keys, and sending prompts only while a session is live.

How you would turn them on

One page in Settings: Claude tools

A new Settings → Claude tools page sits beside Features and Claude mods. Everything ships switched off, so Zendr stays as quiet as it is today until you choose.

  1. Browse by what you needThe page groups tools by job, like "Limits and cost" or "Never lose a conversation". Each card has a preview picture and two lines on what it does.
  2. Flip the switchThe tool appears at once, with no restart. Its toolbar button, keys and panel all go away again when you switch it off.
  3. Open its optionsTools with choices (which limits to show, the hibernate delay, an automation's schedule) open an options box under the card, like the Claude mods page.
  4. See who made itEvery card names the original author with a link to their repo and its licence. The same credits go in Zendr's README and NOTICE file.

How each tool arrives

Port, build, or merge

Port

MIT and Apache-2.0 mods are copied into Zendr's mods and adapted to Zendr's look, Windows, and the Features switch. Their LICENSE file travels with them and the author is named in the mod header, the Settings card and NOTICE.

Own build, idea credited

Repos with no licence can't be copied. Zendr gets its own version written from the idea alone, and the card still says whose idea it was. Two marked "check licence" get read before any code moves.

Merge into what Zendr has

Some ideas fit an existing part better than a new panel: session search goes into Alt+Space search, review comments into the code view, the questions box into the Hub.

Limits and cost

Know how much Claude you have left before you run out.

4

Claude limits strip

First wave

Your 5-hour and weekly Claude limits as two small meters in the status bar, each with a pace tick showing how much of the window has passed. Click for every limit, reset times and a forecast ("at this pace, runs out at 5:24 pm").

Why in Zendr You run several Claude sessions at once, so you burn through limits faster than one terminal shows. Seeing the pace before you hit the wall is the single most useful number for a Claude-first app.
